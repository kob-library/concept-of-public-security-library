# Конвертер КОБ v0.4.1 — внутренний исследовательский инструмент

Это **не подтверждённая редактором публикация**. Вход: исходные Word `.doc` и
соответствующие PDF; результат: полные автоматические Markdown-тексты по главам,
разделам и приложениям, машинные JSONL-индексы, отдельные медиа,
сноски, контрольные суммы и подробная очередь визуальной сверки.

## Запуск

Необходимы: Python 3 с `PyMuPDF`, `PyYAML`, `lxml`, `libreoffice`, `pandoc`,
`magick` (ImageMagick). Не следует устанавливать или запускать от имени администратора.

**Переносимость.** Конвертер пока рассчитан на Linux-окружение: в коде встречаются
абсолютные пути вида `/mnt/data` (в т.ч. `assemble_release.py` жёстко задаёт
`ROOT=Path('/mnt/data')`), а вызовы `libreoffice`, `pandoc` и `magick`
предполагают, что программы доступны в `PATH` с unix-семантикой
(`-env:UserInstallation=file:///tmp/...`). Текстовый ввод-вывод переведён на
явный UTF-8, но полная переносимость на Windows не гарантируется — полный
прогон конвертации проверен только на Linux.

```bash
python convert_corpus.py --input-dir /path/to/input --output-dir /path/to/output \
    --workspace /path/to/workspace --volumes 2 3 4 5 6
python enrich_corpus.py --root /path/to/output \
    --workspace /path/to/workspace --volumes 2 3 4 5 6
python fix_parents.py --root /path/to/output --volumes 2 3 4 5 6
python validate_corpus.py --root /path/to/output --volumes 2 3 4 5 6
```

В исходной папке ожидаются `Основы социологии (том N).doc` и
`Основы социологии (том N).pdf` с одинаковым `N`.
В `workspace` хранится промежуточный `.docx` и сырой Markdown, которые
инвалидируются при смене SHA-256 исходного DOC.

## Состояние конвертации v0.4.1

- Автоматическое разбиение сохранённого Pandoc-текста **не удаляет** абзацы.
- Сноски переносятся к соответствующим выноскам, оригинальные номера не меняются.
- Библиотека `.doc` / `.pdf` и каждый медиафайл DOCX копируются без изменения;
  их контрольные суммы сохраняются в манифестах.
- Изображения, которые Pandoc не смог привязать к Markdown, сохраняются
  отдельно в `assets/media_original`, доступны через `RECOVERED_FIGURES.md`,
  а предполагаемое место описывается в `data/media_anchors.jsonl`.
- Оригинальная верстка, сложные таблицы, рисунки и OLE **ещё требуют ручной
  проверки**, включая проверку вложений. Не публиковать с отметкой «полностью
  выверено» по одному факту прохождения автоматических тестов.
- Автоматические страницы — только **кандидаты**, не окончательно сверенные
  ссылки на PDF.

## Для агентов

Ищите прежде всего `data/chunks.jsonl`; восстанавливайте контекст через
`section_id` и `data/sections.jsonl`, затем открывайте оригинальный PDF.
`page_mapping_status` должен сопровождать ссылки на PDF: если статус
`auto_...candidate`, страницу требуется подтвердить визуально до цитирования.
Авторские политические, научные, религиозные и прочие утверждения — **позиции
авторов в соответствующее время**, а не автоматически доказанные факты.
Служебные README и QA-файлы не являются первоисточниками.

## Публикация

Проверьте источники, точное размещение иллюстраций и правовой статус
конкретных редакций. В этом прототипе никакие документы на публичные
площадки не загружаются. После такой приёмки можно собирать сайт или
GitHub-репозиторий из того же исходного набора.
